# 2 配音

配音演员是用户自己声音的克隆：千问的 Qwen3-TTS（Base 模型，Apple 芯片上的 mlx 版）。怎么录参考音、怎么克隆得更像，开口 kaikou 那个 skill 讲得最细，这里只写剧组多做的几步。

## 准备

- `config.json` 里填 `voice_ref`：一段 10 到 20 秒、干净的本人录音。只能用自己的声音，或者本人同意过的声音。
- 想说快一点，填 `voice_speed`（默认 1.06）。第一次用时会用 ffmpeg 把参考音加快这个倍数，模型就会跟着说快。成品不做时间拉伸，拉伸会出电音。

## 三条命令

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py lines       # vo/草稿.txt → vo/lines.py
python3 ~/.claude/skills/juzu/scripts/juzu.py tts         # 只做文本改过的句子；写了键（tts a03 b02）就强制重做这几句
python3 ~/.claude/skills/juzu/scripts/juzu.py timeline    # 排时间线，出 app/src/timeline.json 和 out/vo.wav
```

- `lines` 把数字换成汉字（「5.5」念「五点五」），把不好念的英文换成好念的写法。配音文本里还剩阿拉伯数字会直接报错。
- `tts` 每句最多念 4 遍，每遍用 Whisper 听写成字，和稿子对一对，留下听写最准、语速最接近目标的那一遍，再把句子里过长的停顿压短。结果在 `vo/me/choice.json`。
- 听写准确率低于 0.9 的句子，`tts` 结束时会列出来。先听一下：有时是 Whisper 听错了（比如「省事」被听成「审视」），配音其实没错；真念错了就换个说法重做。
- `timeline` 定下全片的时钟。画面、混音、字幕都只认 `app/src/timeline.json`。还没配音的时候可以 `timeline --draft`，按字数估时长，先把画面做起来；配完音一定再跑一遍正式的。
- 跑完 `timeline`，在片场里跑 `juzu tl`，把时间线写成 `set/tl.js`，顺便出 `out/字幕.srt`。

## 语速和停顿（66 期作者：「语速稳定一点、平缓一点」）

快慢和停顿写在这一集的 `episode.json`，不用改 config：

```json
"voice": {"speed": 1.04, "rate": 5.52, "tol": 0.05, "keep": 0.40, "longest": 0.60, "takes": 6},
"pause": {"scale": 1.3, "min": 0.55, "section": 1.5, "inner": 0.3, "comma": 0.03}
```

- `voice.speed`：参考音 = 原声加快多少倍（存成 `vo/ref_x<倍数>.wav`）。`rate` 是目标语速（字/秒），`tol` 是允许偏多少：每句至少念 2 遍，直到有一遍听写 ≥ 0.95 而且落在范围里，最多念 `takes` 遍。66 期的参考原声是每秒 5.31 字。
- `pause`：句与句之间停 max(`min`, 句后停顿 × `scale`)，换章节至少停 `section` 秒，句号处多停 `inner` 秒，逗号处多停 `comma` 秒。**开新一集从上一集抄设置时，`pause` 一定要一起抄**（66 期漏了，用的是默认 0.72 / 0.18，作者听着急）。
- 稿子是只用逗号的长句时，`inner` 用不上，靠 `comma` 放缓。66 期：comma 0.03 是原声的 1.036 倍，0.05 是 1.027 倍，0.08 是 1.014 倍。
- 作者说快慢不对、又说不清快多少：先把同一段混音用 `ffmpeg -af atempo=0.94` 之类拉几档给作者听，挑定了再重配（拉伸只用来挑，成品不拉伸）。66 期挑了一圈，作者最后还是要原来那档。
- 改了 `voice` 或 `pause` 以后：

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py tts --repick   # 不用显卡：拿已经念过的每一遍重新压停顿、重新挑
python3 ~/.claude/skills/juzu/scripts/juzu.py tts --off      # 只重配语速超出范围的句子（要显卡）
```

- 设了 `tol` 时，听写差 0.035 以内的几遍都算候选，先挑落在范围里的（「R 星」每遍都被听成「阿星」，0.03 的差只是听写误差）。同音字被听错、其实念对了的，写 `"force": {"d09": 7}` 指定用第几遍。
- 有的句子念几遍都偏快或偏慢（一口气列四段、连着三个顿号），是句子本身的写法，不用硬凑。

## 注意

- 配音要占显卡，不和片场渲染、作曲同时跑。
- 改了稿子：改 `草稿.txt`，重跑 `lines` 和 `tts`（只会重做改过的句子），再跑 `timeline` 和 `tl`。导演表里写的是词，不是秒数，所以大多不用跟着改。

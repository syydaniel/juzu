# 5 拟音

拟音做三样：片场动作的声音、章节换段和互动提示的柔和音效、开场画面底下的环境声。

作者的两句话定了方向。一句是嫌旧音效刺耳：甩动、冲击、故障、亮晶晶那一套全换掉了。另一句是「环境音效可以去网上找现成的，或者在达芬奇里面找，但是都要做好混音」：环境声用真实录音，不用代码合成。

## 规矩

- **少，而且柔。** 起音不短于 8 毫秒，没有「啪」的一下；3 kHz 以上几乎没有能量；不做很重的低频。
- **按最大瞬时响度校准，不看峰值。** 柔和音效 −30 LUFS，片场动作声 −34（更多，所以更轻），环境声整段 −24、再摆到比配乐低 7 LU。
- **同一种声音每次略有不同。** 字块落桌有四个音高轮着用，免得像复制粘贴。
- **新做的声音先单独听。** 每个脚本都会出一条试听（`music/sfx_soft/_试听_*.wav`，时间表在同名 .txt），听过再往片子里放。
- **公开仓库里不放任何声音文件。** 下载来的录音只留在这一集的 `sfx/lib/`。

## 片场动作的声音

```bash
juzu events     # 从导演表 set/shots.js 读出动作时刻 → sfx/events.json
juzu set_fx     # → music/sfx_soft/ 里的动作音效、out/sfx_set.wav、试听条
```

`events.mjs` 认这几种：

| 动作 | 导演表里 | 声音 | 时刻 |
|---|---|---|---|
| 字块落桌 | FX3D 里 `flat` 的 | 木头的「嗒」，四个音高轮换 | 出现后 0.42 秒，和落地动画对齐 |
| 牌子升起来 | FX3D 里有 `pos` 的 | 低频的木头擦过 | 出现时 |
| 立体卡翻出来 | 其余 FX3D | 一小口气 | 出现时 |
| 纸展开 | BOARD | 纸的录音 | 提前 0.8 秒 |
| 图钉 | BOARD 的 pins | 很短很闷的一下 | 晚 0.45 秒 |
| 贴截图 | STICK | 胶带的录音 | 出现时 |
| 小机器人跳进 / 跳出屏幕 | KAKA_IN | 软的「啵」，音高往上 / 往下滑 | 跳进提前 0.8 秒 |
| 字块被推开 | FX3D 的 `off` | 低沉的一推 | 推开时 |
| 手机震一下、翻过来 | PHONE | 闷的嗡一声，再一下翻面 | 嗡在翻之前 0.57 秒 |
| 全息投影亮起来 | HOLO | 很轻的一口气，往上滑 | 出现时 |
| 笔记本打开 | NOTEBOOK | 笔滚开、松紧带弹开、封面翻过去 | 开始后 0.12 / 0.75 / 2.05 秒 |
| 小机器人飞走、飞回 | VISIT、MAGIC | 和跳进跳出同一种「啵」 | 起飞时、落回前 |
| 浮空板上的东西贴上、聚拢 | MAGIC | 胶带、一小口气 | 按悬浮段的节拍 |

纸和胶带用达芬奇自带 Fairlight 音效库里的录音，低通到 3 kHz，从录音里挑最响的几段（随便截一段容易截到安静处，校准时会把底噪放大）。库里找不到就用滤过的噪声代替，脚本会提醒。上面这些都由 `events.mjs` 从导演表里直接推出来，加了新道具就在那里加一条规则；实在推不出来的零星动作才写进 `cues.json` 的 `set_fx.extra`。某一种嫌吵就写进 `off`，音量在 `gain` 里调。新合成的声音都过低通，3 kHz 以上几乎没有能量。

## 柔和音效

```bash
juzu softfx     # 做 air1–3、tap1–4、chime、thud、bloom → music/sfx_soft/
juzu cue_fx     # 按 cues.json 的 sfx_soft 摆 → out/sfx_cues.wav
```

- `air`：章节换段的一口气，带通噪声慢慢滑，`pre` 0.45 秒让它在章节开头之前起来。
- `chime`：点赞时的小铃。`tap`：评论、弹幕引导和报数字时的轻敲。`thud`：片尾卡落下。
- 音高用各段铺底共有的音。`cues.json` 写了 `sfx_notes` 就用写的，不写就从 plan 里找每个音效落在哪段铺底，取这些调的公共音。
- 一集十几处就够。64 期 15 处。

## 环境声

两种用法。一种是开场几段实测画面的蒙太奇，每段底下铺对应的环境声（64 期）。另一种是屋里的戏：整条片子底下垫一层窗外的声音（65 期），让房间不那么「真空」，见本节最后。

**找录音。** 先找达芬奇的 Fairlight 音效库（`config.json` 的 `ambience_dirs`，可以加别的文件夹）：

```bash
juzu ambience --find wind
juzu ambience --find train
```

64 期查过，Fairlight 库里没有火车、风、发动机。这些去免费音效网站下，放进这一集的 `sfx/lib/`，旁边写一份 `来源.md`：网址、编号、许可。很多免费音效站允许商用、不用署名，但不许把原文件单独再分发，所以 `sfx/lib/` 不进任何公开仓库。

**分层。** 每段画面三层就够：

- 底子（bed）：风、沙漠、山顶的空气
- 主体（main）：火车喷气、发动机。按主体到镜头的距离做音量和高频：`distance` 写 `[相对切点的秒, 米]`，12 米时音量不变，更远按 12/距离 衰减；高频截止 9 米时 9 kHz，140 米时 1.1 kHz。远处闷，近了亮。
- 点缀（detail）：铁轨咔哒、悬挂的金属响。可以连续铺，也可以用 `hits` 一下一下放在画面里颠簸的那一刻。

每层的 `level` 是它在这段里的 RMS，用来对齐各层。64 期：风 −23，蒸汽喷气 −21，铁轨 −26（再低切 80 Hz），沙漠风 −25，发动机 −20，悬挂响 −27。

**切点跟画面走。** 画面硬切，环境声也硬切（40 毫秒交叉），下一段提前 0.2 秒淡入。第一段不预卷，不然开头会空一下。整段最后 2 秒淡出。

```bash
juzu ambience   # → music/amb/<名字>.wav，统一到 −24 LUFS
```

做完先单独听，再跑 `juzu stems`，它会把环境声摆到比同一时段的配乐低 7 LU。

`semitones` 正数升调、负数降调，用重采样，长度不变。64 期的发动机其实是升了两个半音（当时脚本注释写的是降），听着合适就行，写的时候注意正负。

**屋里的戏：窗外的声音。** 65 期整条片子都在书房里，底下垫了一层隔着玻璃的窗外声：白天是远处街道的车声，夜里是远处的夜间车流。做法：

- 录音挑中频（400 Hz 到 3 kHz）没有突出东西的段落（没有喇叭、人声、鸟叫），18 秒一截，3 秒等功率交叉接成十几分钟的长循环，放进 `sfx/lib/`，写好 `来源.md`。
- `ambience` 里一段一层 `bed`，每层 highpass 80、lowpass 3 kHz 左右（隔着玻璃就是闷的），白天和夜里的切点和导演表里的灯光同一刀，各段从循环的不同位置起（`start`），免得听出重复。
- `under_music` 写 12：比配乐低 12 LU，几乎听不出来，关掉才发现少了东西。

**屋里的戏：四层背景声（78 期起默认）。** 78 期作者听了同一段画面的 A/B（旧的一层窗外声 / 新的四层），定了「用新的四层」。书房的戏都这么做：

```bash
cd set && node tools/campath.mjs --fps 24 && cd ..   # 逐帧机位（导演表改了镜头就重跑）
juzu amb4                                            # → music/amb/room.wav、out/amb4_events.json（先自己读导演表，写 out/amb4_shots.json）
juzu stems
```

`cues.json` 的 `ambience` 里只留一条：`"room": { "at": 0, "dur": "DUR", "script": "amb4", "under_music": 12 }`。写了 `script` 的条目 `ambience` 不再自己拼，`stems` 直接摆 `music/amb/room.wav`。

| 层 | 是什么 | 怎么放 |
|---|---|---|
| 1 屋里底噪 | Fairlight「Exhaust Fan On Run Off」中间平稳的一段，低通 1.5 kHz | 几乎居中，夜里比白天响 5 dB（外面安静了），不跟镜头 |
| 2 窗外底子 | 白天城市声加很轻的鸟叫，黄昏更闷、鸟叫再低 3 dB，夜里夜间车流（三条 `amb_*.wav`，做法见表下） | 跟着导演表的 LIGHT 换；同一类光连着换（白天换低太阳、夜里补光调暗）不换段，慢慢换的光跟着慢慢交叉 |
| 3 窗外的事 | 车开过、自行车、一阵风吹树叶、一群鸟飞走、远处关车门 | 每 26 到 44 秒一个，最响的那一下落在两句话之间的空当里；同一种至少隔 180 秒；音高、远近、左右每次略不同 |
| 4 屋里细节 | 台灯开关、小卡落地时桌面闷闷的一下 | 台灯真的开了或关了才响（夜里、黄昏亮着，白天关着）；落地跟着 KAKA 的 hop |

第 2 层的三条窗外录音要先拼好放进这一集的 `sfx/lib/`（做过一次就从上一集连 `来源.md` 一起拷过来）。都是从干净的几段里随机取 14–24 秒的块，3 秒等功率交叉拼成 10 分钟，最近用过的地方不马上再用，这样听不出循环：

- `amb_day_city.wav`：Fairlight「Ext City Ambience, Car Drive-Bys, Pedestrian, Air」，只取 1–27.5 秒和 43.5–114.5 秒（28–42 秒有行人说话）。别用「Daytime Ambience with Car Drive-Bys and Crow」，整条都有乌鸦。
- `amb_day_birds.wav`：freesound 409145「London Birds」（CC0），整条随机取块。
- `amb_night_city.wav`：Fairlight「Magnolia Night Traffic Car Bus B」，去掉 50–63 秒那辆特别响的公交，取 1–49 秒和 64–190 秒。

三条规则：

- **跟镜头走。** 窗在 x = 0 的墙上。逐帧算镜头离窗多远、窗在镜头哪边：距离每翻一倍轻 3.5 dB（最多 ±4 dB），亮暗在两个低通版本之间交叉；窗在左边声音就偏左，左右最多差约 6 dB（pan 0.45×，最多 0.4）。背对窗再轻 3 dB，只算背对，侧着不算。第 4 层按台灯、小卡的位置摆左右。
- **跟话走。** 台词空当超过 1.5 秒、章节换段、片尾，第 2、3 层慢慢抬 3.5 dB，起落都 0.6 秒以上，不「泵」。
- **每次都不一样，但能重现。** 随机数种子默认 78（`--seed` 换一套），重跑结果一样。

第 3、4 层都压在 3 kHz 以下，喇叭、狗叫、人声都不放。混进去以后背景声比配乐低 12 LU。交片前跑 `juzu cutcheck`，再量一下 12 kHz 以上（作者听得出切音和「呲呲」声）。

要让作者挑的话就做 A/B：同一段画面，除了背景声别的都一样，各出一条（78 期就是这么定下四层的）。

## 坑

| 现象 | 原因 | 办法 |
|---|---|---|
| 作者说音效刺耳 | 甩动、冲击、亮晶晶起音太快、高频太多 | 换成这里的柔和音效，按上面的规矩做 |
| 代码合成的风声和火车声一听就假 | 合成的 | 用真实录音 |
| 环境声开头空了 1 秒 | 第一段也预卷了 | 第一段 `pre` 是 0 |
| 动作音效全是底噪 | 从录音里截到了安静处，校准时放大了 | 挑录音里最响的几段 |
| 章节气声、小铃在成片里听不到 | 拼配乐时把同名的音效文件覆盖成了空的 | 柔和音效写 `out/sfx_cues.wav`，不和配乐拼接共用文件；出片前用 `juzu publish` 的耳听清单逐个对一遍 |

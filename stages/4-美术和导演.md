# 4 美术和导演

这一步做两件事：把片场往前推一小步，再按口播写导演表，抽帧查到没毛病。片场在这一集的 `set/` 里，导演表是 `set/shots.js`，每种表、每个字段的写法见 `reference/导演表.md`。

## 开工

```bash
cd set
npm install                     # 每一集第一次要装：three 0.186.1 和 playwright-core，node_modules 不跟着复制
python3 ~/.claude/skills/juzu/scripts/juzu.py tl    # app/src/timeline.json → set/tl.js 和 out/字幕.srt
node tools/chk.mjs "$PWD"
node render.mjs --page film.html --sheet 2,20,40,60 --cols 4 --w 640 --q ns=4 --out ../out/check/a.jpg
```

渲染要用本机的 Chrome。不在 macOS 的默认位置，就设环境变量 `CHROME=Chrome 的路径`。

还没配音也能先做画面：`juzu timeline --draft` 按字数估时间线。配完音一定重跑 `timeline` 和 `tl`，再抽帧看一遍。

`juzu new 名字 --from 上一集` 会把上一集的 `set/` 整个带过来，片场的改进一期期往下传。全新开始时用的是模板，里面是一份演示导演表，带着观众逛一遍片场，每一种东西用一次。从它改起。

## 片场里有什么

| 文件 | 管什么 |
|---|---|
| `desk.js` | 书房本身：墙、窗、百叶窗、书桌、显示器、键盘、台灯、书架、椅子。所有尺寸在开头的 `DIM` 表里，单位是米。五种光也在这里（`PRESET`） |
| `bed.js` `photowall.js` `door.js` `shelf.js` `steam.js` | 同一间屋子的另一角：床、床头柜、壁灯、地毯和坐墩；床头上方的照片墙；前墙的门；软木板下的矮书柜；杯子的热气。每样都能关，见 `reference/导演表.md` |
| `magic.js` | 悬浮段：小机器人飞到床角，照片在空中拼成一块板放内容，再飞回墙上 |
| `phone.js` `holo.js` `notebook.js` `lamps.js` | 桌上的手机（震一下、翻过来亮屏）；小机器人打出来的全息屏；桌上的笔记本（小机器人飞过去，用光线拨开笔、掀开封面，读手写的那一页）；台灯和床头灯的灯具。导演表里分别是 `PHONE`、`HOLO`、`NOTEBOOK`（配 `VISIT`），不写就不建 |
| `extras.js` | 让房间看着有人用的东西：软木板、便签、桌面杯印和划痕、打印纸、主机、纸篓、充电座，可选的画和贴纸 |
| `tex.js` `gen.js` | 程序化贴图（木纹、墙面、布料）和占位图。片场不读任何素材图也能完整渲出来 |
| `harness3.js` | 渲染外壳：真实感开关的七级、多次采样、色调和颗粒 |
| `film.js` `film.html` | 成片页面：把导演表接到片场上，`window.render(t)` 画第 t 秒 |
| `screen.js` `screen_fx.js` `board.js` `overlay.js` `fx3d.js` | 显示器内容、屏幕特效、软木板、最上面的 2D 层、立体字 |
| `kaka.js` `char/` `kaka_look.js` | 主持小机器人。`kaka.js` 是 `char/*.ts` 打包出来的；默认浅灰白、蓝灰，名字和颜色由你定（`reference/导演表.md` 文末） |
| `shots.js` | 导演表 |
| `render.mjs` `film.mjs` | 抽帧拼图、出视频、分块渲整片 |
| `tools/` | `chk.mjs` 表的体检，`dbg.mjs` 查页面里的值，`flicker.mjs` 量光抖不抖，`kaka_png.mjs` 重画屏幕里的 2D 小机器人 |

**每一帧只依赖 t。** 随机数都按名字或编号定种子，动画都写成 t 的函数，不读当前时间。这样同一秒渲两次完全一样，可以几个浏览器分块渲，断了接着渲。往片场里加任何会动的东西，都要守这一条。

## 每一期往前走一小步

观众会一期期看下去。片场每期变一点，就一直有新鲜感，也一直在攒手艺。每期挑一两样做，别多：

- 东西动起来：窗外的树影慢慢晃，台灯的灯罩被碰了一下，小机器人多一个新动作
- 光随时间变：导演表的 `LIGHT` 和 `BLINDS` 已经能换光、开床头灯、合百叶。一集十几分钟，可以让太阳一点点往下走，到哪一章天黑
- 屋里多一处小细节：杯子的热气、床头的闹钟已经有了，还可以是窗外下雨、台灯的灯罩歪一点
- 新的信息载体：桌上多一样能写字的东西，屏幕多一种画面，悬浮段的板子上换一种内容

怎么加：

- 每帧要变的东西挂在 `film.html` 里的 `stage.tick`，或者 `desk.js` 返回的 `tick(t)` 里，只用 t 算。随机数也一样：要么用固定种子，要么用 `hash(i)`，别用 `Math.random()`，不然 4K 分块渲时每块的样子不一样，接缝处会跳。会动、会亮的新道具记得加进 `film.js` 的 `stage.envHide`，拍环境反射时把它们藏起来。动得快的东西（飞的、掉的）再挂一份在 `stage.tickFast` 上，运动模糊的每个采样都会推进它。
- 变化要慢、要连续。光一下一下地跳，比不动难看得多。改完用 `node tools/flicker.mjs "$PWD" 秒` 量一个停住的镜头，相邻两帧差要在 0.1 以下。慢慢变暗变亮时，差值会朝一个方向走，这不算抖。
- 新东西先在一个固定机位下单独看：`node render.mjs --page film.html --sheet 20 --cols 1 --w 1280 --q "cam=wide&clean&ns=16" --out ../out/check/new.jpg`。

## 搭新东西、大改片场

照真实感开关（`zhenshi-kaiguan` 那个 skill）的路子，一层一层来，每层截图看过再往下。

**先定规格。** 在 `desk.js` 的 `DIM` 里写下真实尺寸，别处只引用。照真东西量：书桌 1.40 × 0.70、高 0.74，27 寸显示器可视区 0.597 × 0.336，键盘 0.279 × 0.115。尺寸对了，镜头焦距和景深按真实镜头算出来才像。墙角在原点，x 沿背墙向右，z 朝房间里，y 向上。新机位的焦距和光圈，可以先用 `node lens.mjs --mm 50 --f 2 --focus 0.6 --near 0.3` 算一下景深和前后景虚成多少像素。

**再看灰模。** `clay=1` 把所有材质刷成灰色，只看形状、比例和光影的大关系：

```bash
sh sheet.sh views ../out/check/clay.jpg 20 "clay=1&clean" wide talk board side top
```

东西摆得像不像、挤不挤、会不会挡住桌上的字，在灰模阶段就该定下来。

**再一级级加上去。** `level=0` 到 `7` 是七个开关：平涂，直射光和硬阴影，程序化贴图，环境光和反射，软阴影和接触阴影，景深，运动模糊，色调映射和颗粒。

```bash
sh sheet.sh levels ../out/check/lv.jpg 20 "cam=wide&clean" 0 1 2 3 4 5 6 7
```

一级一级看：哪一级加上去以后不对，问题就在那一级。新东西的材质先在第 2 级看贴图，第 3 级看反光，第 4 级看影子落得对不对。

**让房间看着有人用过。** 摆得太整齐就像样板间。模板里已经有：

- 桌面上的杯印、细划痕和灰（一张透明贴片，第 2 级以上才出现）
- 纸篓里几团揉皱的纸
- 百叶窗每片中间下垂 2 毫米，每片角度都差一点，有两片明显歪了
- 杯子挪开以后，原来的地方留着一圈杯印

加新东西也这样：边角磨一点、放得歪一点、留一点用过的痕迹。房间里可以放自己的小彩蛋，颜色要暗、要安静，不解读，不特意给镜头，别抢桌上字的视线。用 `SET.decor` 换画框里的画和手机背面的贴纸，图片要是自己有权用的。

**片场里的图要等加载完再渲第一帧。** 新加的贴图放进 `extras.js` 的 `load()` 里，文件不在就跳过，别在 `desk.js` 里同步加载。

## 写导演表

**按口播的顺序写。** 一句一句往下，这句说什么，镜头看哪、屏幕放什么、桌上掉什么字、小机器人做什么，都写在这句底下。顺序乱了，字就会和嘴对不上。

**时间写成词。** `'c05:关键词'`，少写秒数。配音重做以后，写词的地方自动对上。

**说到什么，画面上就出现什么。** 字、高亮、动画都对准口播里的那个词。桌上的字块落地在出现后 0.42 秒，要它落在某个词上就写 `'c05:词-.42'`。

画面的规矩，一期期返工攒下来的：

- **小机器人不单独占一个镜头讲话。** 它出现的时候，旁边一定有这句话的重点：文字、贴图、截图或者动效。需要时把它和背景虚掉一点，让旁边的字看得清。近景里它在画面右三分之一，左边留给磨砂卡和贴图。近景机位写进 `CALM`，显示器的大标题就不会被画面上沿切掉一半。
- **屏幕上不能只有一张图、一段代码或者一行字。** 观众会不知道在讲什么。每一屏有大标题、要点和会动的图解：表格逐行出现、放大镜、高亮、划掉旧的换成新的、打勾。
- **镜头要动，但不能频繁切。** 推、拉、平移、环绕换着用，别每次都一样。可以硬切。镜头跟着字、画面、动画走，带观众看重点。
- **背景的光不能一抖一抖。** 同一个镜头相邻两帧的平均亮度差在 0.1 以下。
- **开头告诉观众有几章。** 章节进度条在顶上一直留着，当前那章高亮。
- **能用的信息载体都用上。** 显示器、软木板（大白纸从上沿展开）、桌上立起来的牌子、桌面上掉下来的字块、小机器人跳进屏幕、悬浮段的板子。
- **特效要有来处。** 悬浮段的照片要么从墙上揭下来，要么当着观众一点点长出来，不凭空开传送门。一期一两段就够，放在最要紧的那句上，每段至少 12 秒。
- **猛地换光放在硬切上。** 天黑、开灯这种一下子的变化，跟着一个硬切走。
- **桌上的字块躲开遮挡。** 笔记本、手机、键盘都会压住字。安全区是 x 1.12 到 1.97、z .665。
- **看得舒服最重要。** 规矩是从一期期返工里来的，不一定都对。自己看着哪里不舒服，就主动改，改了什么记进运行记录。

数字也在导演表里算：演示表的柱状图，数字是程序从导演表里现数的。片子里说的数字要有出处，能从数据算出来的就别手填。

## 抽帧检查

每改一段，先跑 `node tools/chk.mjs "$PWD"`，再抽帧看。一次只渲几帧，别动不动渲整片。

```bash
node render.mjs --page film.html --sheet 15.8,22,31.6,44.9,47.3,51.6,57.5,64.8 --cols 4 --w 640 --q ns=4 --out ../out/check/b.jpg
```

拼出来的图要真的打开看。挑这些时刻：每个镜头刚开始、字刚落下、动画走完、换屏的前后、小机器人跳进跳出、换光的前后。有悬浮段的话，抽 t0 + 1、t0 + 4、t0 + 7、t1 − 3、t1 − 0.5，看飞、照片长出来、板子亮着、照片飞回墙上。逐张对着看：

- 有没有缺的、黑的、空着的地方。图片没加载出来，渲染时终端会打出「图片没找到」。
- 桌上的字块看不看得见，有没有被笔记本、手机、键盘压住，有没有出画。
- 屏幕镜头里，顶上的标题条有没有被切掉。
- 小机器人在画面里时，旁边有没有这句话的重点。
- 贴图、磨砂卡有没有压住屏幕上的字，有没有和字幕撞在一起。字幕在画面底部，底下留出 150 像素左右别放东西。
- 便签、清单是一行行写出来的。抽到写了一半是正常的，往后抽一点再确认。

挑一两个停住的镜头量一下光：`node tools/flicker.mjs "$PWD" 秒`。

## 样片和 4K

都在 `set/` 里跑。

```bash
node film.mjs --tag s1080 --to 180        # 前三分钟样片，1080，出到 ../out/film_s1080.mp4
node film.mjs --4k                        # 整片 4K，出到 ../out/film_4k.mp4
```

- 先出三分钟样片，走一遍达芬奇，给用户看（停点）。画面、节奏、混音的大方向在这里定。样片过了再渲 4K。
- 4K 每块的秒数自动除以 4。每个浏览器活得短一点，不容易遇到「显卡上下文丢了」。
- 渲染分块进行，中途断了，重跑同一条命令就行，渲好的块会跳过。反过来，改了导演表或片场以后要重渲，先删掉 `../out/seg/标签名/`，或者换一个 `--tag`，不然旧的块会被直接拼进去。
- 视频直接编码成 bt709 视频范围，颜色标签写进文件，达芬奇读进去不会整体变暗。
- 夜里长时间渲染，加 `caffeinate -i` 防止电脑睡着：`caffeinate -i node film.mjs --4k`。
- 悬浮段前后几秒自动用 32 个采样（飞的东西才不会拖出一层层重影），这几秒渲得慢一倍。
- 渲染占显卡，别和配音、作曲同时跑。
- 时间线还是草稿时，`film.mjs` 会提醒。草稿只用来看画面，别出成片。

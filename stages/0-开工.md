# 0 开工

## 建目录

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py new 65_片场 --from ~/videos/productions/64_上一集
```

- 写了 `--from`，片场代码（`set/`）、`cues.json`、`vo/mk_lines.py` 从上一集带过来，素材和成片不带。每一期都在上一期的片场上往前走一点，这是剧组的习惯。
- 第一次用、没有上一集，就不写 `--from`，从 skill 自带的 `template/` 开始。模板里有一段一分半钟左右的示范片：书房、床角、主持小机器人、显示器、软木板、桌上的字块、换光和悬浮段都在，导演表把每种写法用了一遍。
- 建完会在 `set/` 里装 three 和 playwright-core。

## 查环境

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py doctor
```

缺什么它会说。缺配音环境就做不了配音，缺 ACE-Step 就做不了作曲，别的步照常。

## 读上一集

开工前读上一集的 `工作流与经验.md` 和 `运行记录.md`。上一集返工过的地方，这一集别再踩。

## 运行记录

`运行记录.md` 是这一集的账本。每个工种做了什么、花了多久、卡在哪、用户说了什么原话，都记一笔：

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py log 1-编剧 "候选题 3 个，用户选了第 2 个"
```

脚本自己也会往里写（配音念了几遍、时间线多长、混音的响度）。片子里说的数字，从这里取。

# 文案：怎么写得像人在说话

编剧写口播稿时读这一份。两道检查的命令写在 `stages/1-编剧.md`，脚本在 `scripts/copy/`。

这里的数字都来自一项对比真人和 AI 口播稿的研究。只用了聚合的统计量，没有引用任何原文。

## 稿子的格式

稿子写在 `vo/草稿.txt`，一行一句：

```
a01|这段时间呢，我做了挺多 AI 视频的。
a02|真的特别感谢大家一路的支持。【这里配一张粉丝数的截图】
```

键是章节字母加两位序号。`【…】` 里是写给自己的备注，两道检查都会先把它去掉。一句四十个字上下最顺。

## 几条硬规矩

- **第一人称，口语。** 用「我在想」「我觉得」「哎……于是呢」这种说法。说看法、说判断用「我」，带观众往下看用「我们」。
- **拿不准的事只说一句。** 不展开，不替它下结论，说完就往下走。
- **每个数字都要有出处。** 出处记在这一集的 `research/` 或 `运行记录.md` 里，写明日期。找不到出处的数字删掉，或者改成拿不准的说法，只说一句。
- **不知道对方用什么代词的人，不用「他」「她」。** 用名字、账号名，或者「这位作者」「对方」。
- **`config.json` 的 `banned_words` 里的字词一个都不能出现。** flavor.py 会查。

## 真人和 AI 差在哪

### 这组数字怎么来的

研究收了 34 个账号的 102 篇真人知识口播。真人稿是从音频转写的，每篇取前 1500 字。每篇真人稿配一篇 AI 稿：把真人稿的提纲交给 Opus，不给任何写作规则，让它写同一个题目，下面叫「裸写」。

102 对里，72 对用来找规律，30 对留着验证。两边都先去掉标点，用同一个标点模型重新断句，再量。量了 134 个指标，其中 38 个在两边的差别站得住：方向稳定，多数账号一致，留出的 30 对上方向也相同。

几处最好记的：

- **语气词差了快八倍。** 真人句尾常带呢、吧、啊、吗，AI 裸写几乎没有。个人差别也最大：有人每千字十几个，有人不到一个。
- **「我」少一半。** AI 裸写的第一人称里，七成多是「我们」；真人一半是「我」。
- **转折用「但是」。** 「但是」在真人稿里每千词 2.22 次，AI 裸写 0.12 次。拿「但是」开头的句子，真人每千句 23.9 句，AI 1.2 句。反过来，用「可」开头的句子，AI 每千句 9.0 句，真人 1.9 句。以前有条写稿规则让转折多用「可、偏偏、好在、索性、倒是」，和真人正好相反：真人稿里「偏偏、好在、索性、倒是」合起来每千字不到 0.1 次，「但」有 3.8 次。
- **「这个、那个」真人多一倍。** 说话的人会回指刚说过的东西。
- **AI 的词更「好看」。** 四字词和成语更多，换词更勤，同一个说法很少出现第二次。真人会把关键的词翻来覆去地说。
- **真人也不是大白话。** 书面小词（而、与、将、以）真人用得比 AI 多，成语也有，只是没那么密。

AI 拿来起句、明显比真人多的词还有：「最后」（每千句 9.9 对 2.6）、「更」（6.5 对 0.6）、「先说」（5.9 对 0）。score.py 的「偏多的起句」查的就是这几个。

## flavor.py 查什么

一句一句查，有一处就报一处，退出码 1。交稿前必须是 0 处。

| 问题 | 怎么判 |
|---|---|
| 空词 | 赋能、极致、震撼、沉浸、打造、助力、深度、全方位、一站式、重磅、硬核、颠覆、天花板、宝藏、神器、炸裂、封神、匠心、初心、温度、高能、燃爆、史诗级、令人惊叹、叹为观止、不容错过、满满的等 40 个 |
| 套话 | 让我们、值得一提的是、总而言之、综上所述、不难发现、毋庸置疑、在这个、时代、一起来看看、话不多说、接下来、首先、其次、最后、总的来说、可以说、真正的、更是、不仅仅是、而是一种、见证、旅程、探索、魅力、灵魂 |
| 对立句 | 「不是 A，是 B」「不是 A，而是 B」 |
| 递进句 | 「不仅…，更 / 还 / 也…」 |
| 既又 | 「既…又…」 |
| 一字排比 | 「一 X，一 Y，一 Z」 |
| 破折号 | 长的短的都算（U+2014、U+2013），普通连字符 - 不算 |
| 连续感叹号 | 两个以上连着 |
| 四字词扎堆 | 一句里有三个以上前后都是标点的四字短语 |
| 冒号铺垫 | 不到 60 字的句子里用了中文冒号 |
| 表情符号 | 有就报 |
| 整篇太整齐 | 五句以上，句子长度的变异系数低于 0.25 |
| 禁用词 | `banned_words` 里的字词 |

这些规则来自原来的检查器，一条没放宽。有一处要知道：原版查「键|文本」的稿子时连键一起查，句首那个四字短语不算进「四字词扎堆」。默认照原版；加 `--strict` 句首也算，会多报一些。

flavor.py 管的几个套话，真人其实也少量在用，比如「最后」每千字 0.35 次，「首先」0.23 次。这条检查比真人严，是作者自己的口味。照它改到 0 就好。

## 怎么看 score.py 的分数

```bash
python3 ~/.claude/skills/juzu/scripts/juzu.py score vo/草稿.txt
```

第一行是 AI 概率，0 像真人，1 像 AI。**目标 0.4 以下**，超过 0.4 退出码是 1。

参照一下：留出的 30 篇真人稿平均 0.21，其中 4 篇超过 0.5；同样 30 个题目的 Opus 裸写平均 0.85。研究里最好的写法（规则加真人片段做参考）平均也只到 0.49 上下。所以 0.4 已经比那些稿子像人。

输出从上往下：

1. **超出真人常见范围的指标。** 每条写着现在多少、真人常见多少、怎么改，按离得多远排序。
2. **用得偏多的词。** AI 爱用、这篇也用多了的词。各留一处，别的换掉。
3. **偏多的起句。** 同一个词起了好几句。
4. **要看的句子。** 对比强调的句式、连着三个很短的分句，摘了原句的开头。
5. **往「像 AI」推的 10 项、往「像真人」拉的 6 项。** 「贡献」是这一项对分数的影响，正数往 AI 推。

先改哪些：

- 第 1 部分排在前面的几条，和第 5 部分里推得最多、又能靠写法改的项：语气词、连接词、「我」、「这个那个」、长分句、把字句、「起来、下来」、四字词。
- 第 2、3 部分点到的词，改起来最快。
- 有些项跟着题材走，硬改会把稿子改坏：专名多少、数词占比、词性比例。讲自己工作流的稿子，「我」多、数字多、专名少，这是题材带来的。分数被它们推高一点，就让它高一点。

先过 flavor 到 0 处，再看 score。每改一轮，两个都重跑。

## 改的时候别矫枉过正

研究里试过把以前的一套写稿规则交给 Opus 再写 50 个题目。38 个站得住的指标里，22 个离真人反而更远，只有 9 个缩小了一半以上。几个例子：

| 指标 | 真人 | 裸写 | 加了旧规则 |
|---|---|---|---|
| 把字句（每百句） | 7.6 | 8.9 | 16.1 |
| 「起来、下来」（每千字） | 3.6 | 5.4 | 10.8 |
| 书面小词（每千字） | 5.7 | 2.9 | 0.8 |
| 「我们」（每千字） | 4.8 | 3.4 | 1.2 |
| 模板句式（每千字） | 1.8 | 2.8 | 0.7 |

模板句式那一行，规则禁得太狠，降到了比真人还少。书面小词也一样，禁着禁着，稿子比真人还「白」。

反方向也会过头。后来让模型照着「要口语」的新规则写了 20 个题目，它又把口语词堆起来：副词里「挺」每千个 20 次，真人 3 次；「特别」14 次，真人 0.4 次；拿「我觉得」起分句，每千个分句 4.8 次，真人 0.7 次；句尾的「呢」每千句 63 句，真人 27 句。

所以：

- 口语词按需要用，一句话里有它才顺，才放进去。别为了凑数到处撒。
- 一轮只改分数列出的前三四项，改完重跑。
- 分数到 0.4 附近就停。研究里「写完、打分、按问题改」这个循环能把 0.67 压到 0.53，再往下调规则就不动了，硬压只会长出新毛病。
- 改完通读一遍，读着别扭的地方，以耳朵为准。

## 分数只是参考

- 打分器只用一组对比训练：真人稿对 Opus 裸写稿，72 对。它认得的是 Opus 不加规则时的样子。换别的模型、换写法，它不一定认得出来。
- 研究里还有一把只看字组合的尺子，各种新写法几乎都没让它动。也就是说，score 的分数降下来，不等于稿子真的像人了。
- 训练用的真人稿都是讲外部知识的，每篇 1500 字。讲自己经历的稿子、很短的稿子（几百字），分数都不太稳。
- 拍板的是你自己的耳朵。能做盲测更好：把这篇稿子的几段和真人稿的片段混在一起，让人挑哪段像 AI。

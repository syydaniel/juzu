# 导演表

`set/shots.js` 是导演表。它导出一个函数，拿到 `TX`（把时间写法换成秒）和 `TL`（时间线），返回一个对象，里面是一张张表。片场的每一帧只看两样东西：这张表和时刻 t。同一个 t 永远画出同一帧，所以可以分块渲、断了接着渲。

新的一集从模板里的演示表改起。演示表是十一句口播、一分半钟左右，带观众逛四个地方（显示器、桌面和小机器人、软木板、床角），每一种东西都用了一次。想知道某种写法长什么样，先去演示表里找。

## 时间写法

导演表、`cues.json`、混音脚本都认这一套。

| 写法 | 意思 |
|---|---|
| `12.5` | 第 12.5 秒 |
| `'c05'` | c05 这句开始 |
| `'c05$'` | c05 这句结束 |
| `'c05:关键词'` | 念到这个词的那一刻 |
| `'c05:关键词+0.4'`、`'c05-.3'`、`'c05$+.2'` | 在前面算出的时刻上往后（+）或往前（-）挪几秒 |
| `'END'` | 片尾卡开始（时间线里的 `end_card`） |
| `'DUR'`、`'DUR-1.2'` | 全片结束 |

几点要知道的：

- 键就是 `vo/草稿.txt` 每行开头的键：章节字母加两位数，`a01`、`b03`。
- 关键词在这句的字幕文字里找（草稿里写的字，不是配音文本），取第一次出现的位置，再按字在分句里的位置换算成秒。同一句里出现两次的词，写长一点，让它只出现一次。
- 找不到会报错：「c05」里找不到「某词」。改了稿子先跑一遍 `chk.mjs`。
- 还没配音时，时间线是按字数估的（每秒 5.3 个字，`timeline --draft`）。配完音重跑 `juzu timeline` 和 `juzu tl`，写成词的地方自动对上新的时刻，写成秒数的地方要手改。所以尽量写词，少写秒数。
- 按口播的顺序写。同一张表里，后一条的时刻不要比前一条早（`KAKA` 可以穿插）。顺序乱了，屏幕上的字就会和嘴里说的对不上。

## 有哪些表

| 表 | 管什么 |
|---|---|
| `KAKA_AT` `CAMS` `SET` `KAKA_LOOK` `DATA` `VOICE_ENV` | 片场设置：小机器人站哪、固定机位、房间布置（床角、门、书柜要不要）、小机器人颜色、录屏数据、口型包络 |
| `LIGHT` `BLINDS` | 光：整期一种光，或者随着片子换（夕阳、白天、黄昏、夜里、床头壁灯）；百叶窗开合 |
| `CAM` | 镜头：什么时候换到哪个机位，怎么动 |
| `SCREEN` `CALM` | 显示器里放什么；哪些机位里显示器只留安静的底 |
| `FX3D` | 片场里的立体字：桌上掉下来的字块、立着的牌子、镜头前的字卡 |
| `BOARD` | 软木板上那张大白纸写什么 |
| `KAKA` | 三维小机器人的姿势、表情、看哪 |
| `KAKA_IN` | 小机器人跳进屏幕里指东西 |
| `PHONE` `HOLO` | 桌上的手机翻过来亮屏；小机器人打出一块全息投影 |
| `NOTEBOOK` `VISIT` | 桌上的笔记本被光线掀开，书页上写字；小机器人飞到桌上别处办事再飞回来 |
| `MAGIC` | 悬浮段：小机器人飞到床角，照片在它头顶拼成一块板，板上放这一句的内容，讲完照片飞回墙上 |
| `GLASS` `STICK` | 叠在最上面的磨砂信息卡、贴图 |
| `TITLES` `CHAPTERS` `PROGRESS` | 大标题、章节卡、顶上的章节进度条 |
| `CTA` | 点赞、评论、弹幕的引导 |
| `HERO` | 整屏画面（真实录屏、实拍的片段） |
| `FADES` `NOSUB` `BADGE` `NOBADGE` | 黑场、不画字幕的时段、右上角系列标 |
| `NS` `GESTURE` `STEAM` | 出片时哪几秒多采样；说话时手比不比划；杯子冒不冒热气 |
| `SAFE` `KAKA_CAMS` | 只给 `chk.mjs` 用：字块安全区、哪些机位算小机器人镜头 |

不用的表写空数组，或者干脆不返回。

## 主持小机器人

片场里的主持是一个小机器人，文档里叫它「主持小机器人」，简称小机器人。模板里的它是浅灰白的壳、蓝灰的手脚和天线头，没有名字。给它起个名字、换一身颜色，就是你自己的角色了，写法见文末「给小机器人起名、换颜色」。代码里它一直叫 `kaka`（`KAKA`、`KAKA_AT`、`kaka.png`），这只是变量名，不会出现在画面上。

## 片场设置

**KAKA_AT** `{ x, z, s }`：小机器人站在桌面上的位置（米）和大小。默认 `{ x: 1.93, z: .36, s: .072 }`，在显示器右边，身高约 0.23 米。

**CAMS** 固定机位，名字随便起：`{ p: [x, y, z] 机位, l: [x, y, z] 看向, mm 焦距, f 光圈值, focus: [x, y, z] 对焦点, drift }`。坐标是米，墙角在原点，x 沿背墙向右，z 朝房间里，y 向上。模板里有 `wide wide2 host host2 talk board side low top`，床角那边有 `room`（整间屋子，窗、书桌、床角都在）、`bedwide`（床角全景）、`bedclose`（床头近景），悬浮段用 `magic` 和 `magicwall`（见 MAGIC）。`talk` 是小机器人讲话的近景，它在画面右三分之一，左边虚掉的地方留给磨砂卡和贴图。

**SET** 房间布置，每一项都可以不写：

- `note: ['先灰模', '再打光']`：墙上便签的两行字
- `slip`：软木板上手写纸条的字
- `paper`：桌上那叠打印纸最上面一张的标题
- `prints: [地址 × 6]`：软木板上六张照片。不写或文件不在，就用程序画的风景占位
- `decor: { painting, sticker }`：画框里的画、手机背面的贴纸。文件不在就保持默认
- `clock: 16.8`：床头闹钟开场时指着几点（小时，16.8 是 16:48），之后跟着片子的时间走

**片场里的东西，每样都可以关掉。** 导演表 `SET` 里写 `false` 是整期不要，网址上加 `?no…` 是查片场时临时去掉、做对比：

| 东西 | 文件 | 关掉 |
|---|---|---|
| 床角：床、被子、枕头、抱枕、毛绒小熊、床头柜（闹钟、书）、床头壁灯、床边地毯、针织坐墩 | `bed.js` | `bed: false` 或 `?nobed`。悬浮段的小机器人照样飞，没有照片 |
| 床头上方的照片墙：28 张程序画的方照片，和纸胶带贴着 | `photowall.js` | `photos: false` 或 `?nophotos` |
| 前墙上的门和开关 | `door.js` | `door: false` 或 `?nodoor`。前墙踢脚线跟着接上 |
| 软木板下面的矮书柜 | `shelf.js` | `shelf: false` 或 `?noshelf` |
| 杯子上的一缕热气 | `steam.js` | 导演表写 `STEAM: false`，或 `?nosteam` |

这些东西全是代码搭的，贴图也是代码画的，不读任何图片。

**图片地址** 可以是 `media/` 下的文件，也可以是程序画的占位图（`gen.js`），屏幕、贴图、软木板都认：

- `gen:print/N`：一张风景照（天色、太阳、几层山、雾）。N 换一组颜色
- `gen:flat/N`：同一张，只有平涂色块，当「改之前」
- `gen:clay/N`：同一张，刷成灰模，只看形状

同一个 N 每次画出来都一样。真图到了，把地址换成文件就行。

**LIGHT** 光，见下面「LIGHT 光和 BLINDS 百叶」。

**KAKA_LOOK** 给小机器人换颜色，见文末「给小机器人起名、换颜色」。

**DATA** 终端录屏的数据：`{ 名字: 'data/xxx.json' }`，给屏幕的 `term` 用。

**VOICE_ENV** 配音的响度包络，`vo/env.py` 生成，默认 `'data/voice_env.json'`。小机器人的嘴和胸口的灯跟着它动。文件没有时，它按每句的起止假装说话。

## LIGHT 光和 BLINDS 百叶

**LIGHT 写一个名字，整期一种光；写成一张表，光随着片子换。** 五种光：

| 名字 | 什么样 |
|---|---|
| `lowsun` | 低太阳，默认。暖色，百叶的影子斜着落在墙上 |
| `day` | 白天，太阳高，光偏白 |
| `afternoon` | 下午，太阳高，光偏暖白 |
| `dusk` | 黄昏，太阳贴着地平线，橙红，台灯已经开了 |
| `night` | 夜里，窗外是黑的，台灯和屏幕当光源 |

表的写法，每一行是一个时刻换成的光：

```js
LIGHT: [{ at: 0, p: 'lowsun' }, { at: 'e01:天一黑', p: 'night', bed: 1, d: .01 }]
```

- `at` 什么时候开始换，`p` 换成哪种光（也可以直接写一组数，字段和 `desk.js` 里的 `PRESET` 一样）
- `bed` 床头壁灯，0 关、1 全亮，中间是调暗。不写就是关
- `d` 用几秒换过去，默认 4

**猛地换光（d 小于 0.5）要放在硬切上。** 墙面、金属上的反光（环境光）只在硬切那一刻、或者硬切之后一次换光（转百叶）走完的那一刻重新拍；光正在慢慢变的那几秒每帧都拍。拍的时刻只由 t 决定，拍之前会先藏起会动、会亮的东西（小机器人、飞的照片、全息、手机屏、字块、热气），显示器换成固定的暗屏，所以分块渲和连着渲亮度一样，画面不抖。镜头中间猛地换光，直射光变了、反光还停在上一种光，看着假；放在硬切上，两样一起变，观众只觉得「天黑了」。慢慢换（几秒以上）可以放在镜头中间。`chk.mjs` 会查。

**书桌的戏别用 `day` 和 `afternoon`。** 这两种光太阳高，直射光只落在窗下的地板上，书桌和背墙渲出来发灰、发暗。书桌用 `lowsun` 或 `night`；`day`、`afternoon` 只给床角那边用，换之前先抽一帧看。

**BLINDS 百叶** `[{ at, a, d }]`：`a` 是百叶的角度（弧度），-.5 是平时，-1.35 差不多合上，-.15 几乎全开；`d` 用几秒转过去（默认 1.6）。转的时候每片错开一点，像手拉的；桌面和床上的光条跟着扫过去。演示表里太阳快下山时百叶慢慢合上，紧接着硬切到床角，天黑，床头灯亮：

```js
BLINDS: [{ at: 0, a: -.5 }, { at: 'e01:百叶-.6', a: -1.35, d: 1.6 }]
```

查片场时在网址上临时固定：`?light=night` 一种光，不跟导演表走；`?lt=night&bed=1` 同上，带床头壁灯；`?bl=-1.35` 百叶角度。

## CAM 镜头

每一条是 `{ at, cam, d, … }`，按时刻排。`at` 是这个镜头开始的时刻。

**d 怎么从上一个镜头过来。** `d: 0` 是硬切。`d: 2.4` 是用 2.4 秒滑过去（位置、看的点、焦距一起走）。不写 d 就是滑 2.2 秒。

滑的时候中间不往后让：推进里夹一下后退，看着像「卡一下、来回推拉」。两头都近、怕擦着屏幕过去，才写 `arc: .06`（米）让一点。对焦按「离镜头多远」在对数上单调地走，比镜头快一点（先把焦点交过去），光圈也在对数上走，所以滑过去时不会虚实来回。

**固定机位**（`cam` 写 CAMS 里的名字）可以加一种运镜，写在 `move` 里，在镜头时长里走完：

- `push: .06`：往看的点推近，数字是走完全程的比例
- `orbit: 8`：绕着看的点转几度
- `rise: .1`：升（负数是降），米
- `pan: .2`：横移，米
- `zoom: 6`：焦距加几毫米

不写 move 默认 `{ push: .08 }`。`move: 0` 是不动。`drift: [dx, dy, dz]` 是每秒漂多少米，很慢地动，用在全景里。`focus` 改对焦点，`fk: .3` 把焦点拉到镜头前的立体字卡上，后面虚掉。`mm`、`f` 可以临时改焦距和光圈。

**rack 拉焦**：`rack: [[时刻, [x, y, z]], …]`，一个镜头里对焦点按时刻一个个拉过去，每次 0.5 秒。第一项的时刻不用，是镜头开始时的焦点。哪种机位都认。比如字块落下立起来，焦点从这块拉到那块：

```js
at('c01', { cam: 'low', d: 0, rack: [['c01', [1.30, .79, .665]], ['c01:落地那一下', [1.64, .79, .665]]] }),
```

**看屏幕** `cam: 'scr'`：

- `u, v`：对着屏幕上哪一点（左上 0,0，右下 1,1）
- `dist`：离屏幕几米
- `yaw, pitch`：从侧面、从上面看几度
- `u2 v2 dist2 yaw2 pitch2 mm2`：写了就在镜头时长里移过去，跟着屏幕上的内容走。`span` 是走完要几秒
- `creep`：停住以后再极慢地推一点，默认 .04，写 0 就完全不动
- `mm` 默认 50，`f` 默认 5.6

演示表里有两个常用的：`FULL = { cam: 'scr', u: .5, v: .5, dist: .95, mm: 50 }` 整屏；`JUMP` 斜着看，屏幕和右边的小机器人都在画里，小机器人跳进屏幕时用。

**屏幕镜头要看见顶上的标题条。** 规则：u .5 时 dist 不小于 .88；dist .84 时 u 在 .48 到 .52 之间；整屏用 dist .95。`chk.mjs` 会算画面上沿和左沿落在屏幕哪里，上沿低于 0.06 或左沿右于 0.05 就提醒。

**看桌面** `cam: 'desk'`：俯看桌面前沿，跟着桌上的字块走。

- `x, x2`：看的点从 x 走到 x2（米）
- `h, h2`：镜头比桌面高多少（默认 .40）
- `back, back2`：镜头往后退多少（默认 .32）
- `z`：看的那一排在多深（默认 .665，正好是字块那一排）
- `side`：镜头往左右偏，`mm`（默认 32）、`f`（默认 4）、`span`

演示表里用的是 `{ cam: 'desk', d: 0, x: 1.22, x2: 1.55, h2: .64, back2: .44, mm: 30, f: 2.8, span: 7.5 }`，整排字块都在画里。小机器人站得靠后，这个角度能看到它的脚，算正常。

**动和切的规矩**

- 镜头要动，但别频繁切。推、拉、平移、环绕换着用，别每次都推。
- 换内容、换地方，干脆硬切。同一处看下一个重点，滑过去。
- 一个镜头至少 3.5 秒（`smooth()` 会把更短的并掉），再短观众还没看清。后面接的是滑过去的，可以短。
- 跟着字走：屏幕上要点一条条往下出，镜头的 `v2` 就跟着往下。

**运镜顺滑：`smooth()`**（66 期作者看样片：「运镜的时候一顿一顿的，明明已经推过去了，突然又跳到了后面……运镜要丝滑」）

`shots.js` 在 CAM 写完、LIGHT 定好以后调用 `smooth(CAM, TX, TL.duration, CAMS, { cuts })`，导演表本身不用改。它做五件事：

1. 整屏镜头（写了 `full: 1`）往下看一点、离远一点，屏幕最底下一行不压字幕；
2. 同一个机位连着的几个镜头并成一个，前一个的运镜一直走到下一个机位（不再「推到 1.0、下一个又从 1.02 起」那样往后跳）；
3. 夹在两个相同机位中间、不到 4.5 秒的短镜头去掉（道具镜头留着）；
4. 剩下不到 3.5 秒、又不是道具的镜头并进前一个；
5. 同一片区域的两个机位之间（小卡的近景和中景、屋子的几个远景）硬切改成滑过去，滑多久按走多远、转多少度定：峰值压在每秒 0.6 米、30 度左右，1 到 4.5 秒；并出来的整屏长镜头超过 7 秒的，加 ±2.2 度很慢的左右横移，一左一右交替。

不想被动的镜头写 `keep: 1`；每章开头（`a01`、`b01`……）自动留着。`cuts` 是一串必须硬切的时刻，模板里直接取 LIGHT 里换光的那几刀：66 期 c01 的黄昏光是瞬间换的，被改成滑 1.5 秒以后，光在滑的开头一下子变了。处理记录在 `window.SMOOTH_LOG`；`node tools/campath.mjs` 逐帧读机位，看滑过去的峰值速度、有没有不在硬切处的跳动。

## SCREEN 显示器

每一条是 `{ kind, t0, t1, … }`。时间上首尾相接，中间别留空档（`chk.mjs` 会查）。

所有种类都认的字段：

- `title`：窗口标题栏里的小字。`sub`：标题栏右边金色的小字
- `head`：标题栏下面那行大标题。可以是一句，也可以随着话换：`[['b01', '第一句'], ['b01:要点', '第二句']]`
- `tr`：怎么换上来。不写是淡入，`'push'` 整页从右边推进来，`'rise'` 从下面升上来，`'cut'` 直接换
- `fx`：叠在画面上的特效，见下面

**屏幕上不能只有一张图、一段代码或一行字。** 每一屏有大标题（`head`），有要点，有会动的图解。

**CALM** `['talk']`：在这些机位的镜头里，显示器只留一层安静的底色，不画标题和字（`picture video filmstrip versus tri` 这几种照常放）。小机器人近景里显示器在画面边上，大标题会被画面上沿切掉一半，还糊在顶上的章节进度条上，不如不画。重点放在旁边的磨砂卡和贴图上。

| kind | 画什么 | 字段 |
|---|---|---|
| `list` | 清单，一条条亮起来 | `items: [{ text, sub, at, hl, strike, fix }]`，`big` 字号（默认 38），`subSize` 小字字号（默认 22），`num` 带序号，`lhead` 清单上面一行，`center: 1` 整块横向居中（悬浮段的板上用，不然字只占左边三分之一）。`gap` 行距、`top` 第一行离标题栏多远（设计稿像素，默认按条数排满、90）：悬浮板上字大、条数少时自己写。`hl` 这一刻荧光笔扫过，`strike` 这一刻划掉，`fix` 划掉后跟出来的新写法 |

| `bars` | 柱状图，柱子一根根长出来 | `rows: [{ k 名字, v 数, label, at, hl }]`，`max`，`unit`，`dec` 小数位 |
| `versus` | 两张图左右对比 | `a: { src, tag, cap, zoom, fx, fy }`，`b` 同样 |
| `picture` | 一张图 | `src`，`fit: 'contain' 或 'cover'`，`kb: [z0, z1, fx0, fy0, fx1, fy1]` 慢推，`tag`，`cap` |
| `video` | 视频帧 | `dir`（放 `f0000.jpg` 这样的帧），`fps`，`n`，`start`，`loop`，`tag` |
| `term` | 终端录屏回放 | `cast` 数据名（DATA 里的），`map: [[全片秒, 录屏秒], …]` 可以快放，`rows` 放大几行，`hl`，`find`，`clock` |
| `code` | 代码 | `file`，`lines: [[行号, 文字]]`，`hl: { 行号: 时刻 }`，`note`，`noteAt` |
| `words` | 一句大字或一个数 | `big`，`small`，`kicker`，`size`，`col`，`mono` |
| `bigwords` | 大字，字一个个浮上来，背景在流动 | `big`，`small`，`kicker`，`size`，`col`，`kSize` kicker 字号（默认 30），`sSize` small 字号（默认 32） |

屏幕的设计稿是 1600×900（含 46 高的标题栏），实际画在 3200×1800 的画布上。写坐标都按 1600×900。屏幕里认不出的 kind 会直接报错。

**fx 特效** `fx: [{ type, at, to, … }]`，`at` 出现，`to` 消失（不写就跟到这一屏结束）。位置有三种写法：`{ u, v }` 在图里的比例（versus 要加 `side: 0 或 1` 说哪一张），`{ x, y }` 设计稿坐标，`{ find: '字' }` 终端里第一次出现这段字的地方。

- `ring`：手画的红圈，一笔画出来。`rx, ry` 半径
- `hl`：荧光笔从左往右扫过。`w, h` 范围
- `lens`：放大镜。`r` 半径，`z` 倍数，`dx, dy` 把镜片挪开，原处留一个虚线圈
- `arrow`：箭头，从 `x1, y1`（或 `u1, v1`）画到目标
- `line`：一道线画过去，`dash` 虚线
- `dim`：尺寸线，中间写 `text`
- `label`：弹出来的一块说明，`text`，`size`，`bg`，`fg`

## FX3D 片场里的立体字

三种，看写了哪个字段：

- **`flat: [x, z]` 桌上的字块**：从上面掉到桌面上，平躺着。每块按自己的文字定一组随机数：落地角度、前后错开、从多高掉、空中怎么翻、落地后晃两下，每次渲染都一样。**落地时刻固定在出现后 0.42 秒**，拟音按这个时刻放「嗒」。想让字块正好落在某个词上，就写 `at: 'c01:嗒-.42'`。`hgt` 字块纵深（默认 .065 米），`yaw` 转角，`hl` 说到时抬起来发亮（可以是一个或几个时刻），`col` 字的颜色，`size` 字号，`minW` 最小宽度。`stand: 时刻` 那一刻字块以靠镜头的那条边为轴立起来，稍微后仰，晃一下停住。`bed: true` 字块落在床上的被子上（`flat` 写床上的 x、z），被子鼓的地方就落得高一点。
- **`pos: [x, z]` 立在桌上的牌子**：从桌面里升起来，到 t1 前沉回去。`hgt` 牌子高（默认 .12），`yaw` 朝向，`tilt` 后仰。
- **都不写：镜头前的字卡**：在出现那一刻按当时的镜头摆在画面里，之后留在原地，镜头再动就有视差。`x, y` 画面里的位置（宽高的比例，0 是中心），`vh` 卡高占画面高的比例（默认 .16），`dk` 离镜头的距离是对焦距离的几倍（默认 .8），`style: 'num'` 配 `num` 写一个大数，`kicker`，`sub`，`serif`，`mark` 金色划线。

字块还可以写 `off: 时刻`：那一刻它被推下桌，先抖一下（像不情愿），再往桌沿滑、越滑越快，过了桌沿翻着掉出画面。用在「这个不要了」的那句上。

共同字段：`text`，`at`（或 `t0`），`t1`。演示表里的 `fl(文字, 出现, 消失, x, 其他)` 是写字块的简写。

**字块的安全区：x 1.12 到 1.97，z .665。** 左边是笔记本，右边是手机，前面是键盘，超出去就会被压住。`chk.mjs` 会按字数估每块多宽（字号 64 的两字块约 0.11 米宽），出界或者两块压在一起都会提醒。换了房间布置，在导演表里写 `SAFE: [左, 右]` 告诉它。

## BOARD 软木板

镜头对着软木板时，一张大白纸从上沿展开。

- `{ kind: 'note', t0, t1, title, size, lines: [{ text, at, mark, hl, strike, ring, sub, col }] }`：手写清单。`mark: '✓'` 打勾，`'✗'` 打叉；`hl` 荧光笔；`strike` 划掉；`ring` 圈起来
- `{ kind: 'pins', t0, t1, title, pins: [{ src, at, x, y, w, rot, cap, ring: { u, v, r, at } }] }`：钉照片，一张张落下来、钉上，下面手写一行

## KAKA 小机器人

`{ at, pose, face, look, hop, act, d }`：这一刻换成什么姿势、什么表情。`look: 'screen'` 看屏幕，不写就看镜头，也可以写一个角度。`hop: 1` 跳一下。`act: 'nod'` 点头、`'shake'` 摇头，1.1 秒，一下比一下小。`d` 换姿势用几秒（默认 .45）。说话时嘴和胸口的灯自己会动，表情没写或者写 `speak` 时会张嘴。

姿势 pose：`stand happy point reach pointUp think shrug surprise present presentBoth cheer sad listen check wave thumbsUp proud heartHands bashful dizzy`

表情 face：`neutral blink happy surprised focus doubt sad dizzy embarrassed proud heart wink standby listen speak code star ai`

**说话时手会自己比划。** 每个分句开头抬一下手，左右轮流，说完放下；只在两手垂着的姿势里比划，导演表写了动作的地方不动。不想要就写 `GESTURE: false`。

悬浮段（MAGIC）里小机器人的飞、落、举手由悬浮段自己管，那段时间 KAKA 里写的姿势不起作用；板子亮着时的姿势在 MAGIC 的 `pose` 里写。

**小机器人不单独占一个镜头讲话。** 它在画面里的时候，旁边一定有这句话的重点：磨砂卡、贴图、立体字或者标题。`chk.mjs` 会查 `talk host host2` 这几个机位（导演表里写 `KAKA_CAMS` 可以改），超过四分之一的时间旁边空着就提醒。

## KAKA_IN 小机器人跳进屏幕

```js
{ t0, t1, path: [[时刻, x, y, 大小, 翻转], …], say: [{ text, at, to, dx }] }
```

x、y 是脚底在屏幕设计稿（1600×900）里的位置。挪位置时跳着走。`say` 是气泡，`dx` 气泡往左右挪。跳进屏幕前后，三维的小机器人会缩小、飞进屏幕；这段时间镜头用 `JUMP` 这类同时看得到屏幕和小机器人的角度，跳完再滑到整屏。

屏幕里的 2D 小机器人是 `media/kaka.png`。改了它的样子，要重画这张图（见文末「给小机器人起名、换颜色」）。

## MAGIC 悬浮段

一句话讲到要紧处，小机器人从桌上飞起来，落在地毯上的针织坐墩上，举起两手；床上的毛绒小熊、闹钟、书慢慢浮起来；照片在它头顶一张张长出来，拼成一块 16:9 的板，板上放这一句的内容。讲完照片翻回正面，飞到床头上方的墙上贴好，小机器人飞回桌上。从这以后墙上就一直是这面照片墙。要床角和照片墙都在（`SET.bed`、`SET.photos` 不能关）。

```js
MAGIC: [{ t0: 'e02', t1: 'e02$+1.4', float: ['plush', 'clock', 'book'],
  panel: { kind: 'bigwords', kicker: '悬浮段 · MAGIC', big: '板上也能放字', small: '和显示器同一套画法', size: 110 } }]
```

| 字段 | 意思 |
|---|---|
| `t0` `t1` | 起飞、落回桌面的时刻 |
| `from` | 照片从哪来。`'air'`：从小机器人手心上方一粒粒长出来；`'wall'`：本来贴在墙上，被揭下来。第一段默认 `'air'`，之后默认 `'wall'` |
| `float` | 举手时浮起来的东西：`plush` 毛绒小熊、`cushion` 抱枕、`pillow` 枕头、`clock` 闹钟、`book` 床头柜上的书 |
| `pose` | 板子亮着时小机器人的姿势，默认 `presentBoth` |
| `end` | 写 `'gather'`：讲完照片不上墙，金线倒着收、缩回一粒粒光点，飞回小机器人手心。适合放在前半段，照片墙留给后面那段第一次贴 |
| `panel` | 板上放什么。写法和 SCREEN 的一屏一样（`kind` 加各自的字段，按 1600×900 写），不画窗口标题栏。另外几项管板子本身：`c: [x, y, z]` 中心（默认 `[1.78, 1.02, 2.33]`，在小机器人头顶稍后），`yaw` 朝向几度（默认 135，正对书桌那个角，和床、前墙都斜着），或者 `face: [x, y, z]` 朝向某一点，`tilt` 往上仰几度，`w` 板宽（米，默认 .9），`t0` 内容什么时候亮。板上要讲几样，写 `parts`（见下） |

**板上分几段**：`panel` 里写 `parts: [{ until, kind, … }, …]`，每段是一屏（写法同 SCREEN），`until` 是这段讲到哪一刻，最后一段不写。到点交叉淡化 0.4 秒。清单放在板上记得写 `center: 1`。

```js
panel: { w: .9, parts: [
  { until: 'e02:拼成-.3', kind: 'bigwords', kicker: '悬浮段', kSize: 44, big: '板上也能放字', size: 136, small: '和显示器同一套画法', sSize: 50 },
  { kind: 'list', title: '板上', big: 78, subSize: 42, center: 1, items: [{ text: '分几段', at: 'e02:拼成' }, { text: '交叉淡化', at: 'e02:板上' }] }] }
```

**一段至少 12 秒。** 时间是按 t0、t1 往里排的：

| 时刻 | 发生什么 |
|---|---|
| t0 | 起飞，脚底两团推进的光 |
| t0 + 1.7 | 落在坐墩上，坐墩被压扁一点 |
| t0 + 1.9 到 2.3 | 举手；东西浮起来；第一张照片开始长 |
| t0 + 5.6 | 板子拼好，内容亮起来（`'wall'` 段是 t0 + 6.0） |
| t1 − 4.4 | 内容灭掉，照片翻面、飞回墙上 |
| t1 − 2.6 | 照片都贴好了 |
| t1 − 1.6 | 小机器人起飞回桌上 |
| t1 | 落回桌面 |

所以配音里要放在板上的那句话，要落在 t0 + 5.6 到 t1 − 4.4 之间。不够长就在 `vo/mk_lines.py` 的 `PAUSE` 里给这句后面多停一会儿（演示表 `PAUSE = {'e02': 1.6}`），`t1` 写成 `'e02$+1.4'` 这样往后延。短于 12 秒页面会在控制台提醒，`chk.mjs` 也查；两段不要叠在一起。

**镜头。** 演示表里是这样排的：起飞前 0.3 秒硬切到 `room`（整间屋子，看它从桌上飞到床角），落地后硬切到 `magic`，收的时候软切 1.4 秒到 `magicwall`：

```js
at('e02-.3', { cam: 'room', d: 0, drift: [-.01, 0, -.01], move: 0 }),
at('e02+2.2', { cam: 'magic', d: 0, move: 0 }),
at('e02$-2.6', { cam: 'magicwall', d: 1.4, move: 0 }),
```

- `magic`：屋子右后角，36mm、f/1.4，焦点在板子和小机器人上（约 2.3 米）。大光圈让板子和后面的墙、门分得干净
- `magicwall`：同一个位置，28mm、f/2.8，焦点在床头上方的照片墙，照片飞回去那段用

**快的那几秒要多采样。** 飞的小机器人、照片在 16 个采样下，运动模糊是一层层的重影；32 个采样时每层只隔约 3 像素，看不出分层。出片时（网址上的 `ns` 不小于 12），`film.html` 自动把每个悬浮段前后各多 0.3 秒升到 32 个采样，这几秒渲得慢一倍。VISIT 的起飞和飞回也自动算。别处也有快的东西，在导演表写 `NS: [{ t0, t1, ns: 32 }]`。抽帧检查用 `ns=4`，不受影响。照片飞的时候金线自己会压暗，细亮线在运动模糊里会拖成一道道光带。

## GLASS 和 STICK

都按 1920×1080 的设计稿写。

**GLASS 磨砂信息卡**：把那一块三维画面虚化、压暗，上面写字。镜头离开屏幕时，重点写在这上面。

`{ t0, t1, x, y, w, h, kicker, title, tsize, lines: [{ text, at, hl, sub, size }], num, unit, numAt, nlab, blur, anchor, minW, fit }`

`num` 写一个大数，`numAt` 说到它时再数上来。

**卡的大小按字量出来**：宽是最长那行加两边留白，高是最后一行加底边留白。手写的宽高一改字就对不上，框比字大一圈，或者字跑出框。`x`、`y` 是左上角；`minW` 最小宽度（默认 300）；`fit: false` 才用手写的固定 `w`、`h`。靠下的卡写 `anchor: 'bottom'`：底边钉在 `y + h`，字多了卡往上长，不压字幕：

```js
{ t0: 'c02', t1: 'c02$', x: 90, y: 660, w: 780, h: 280, anchor: 'bottom', kicker: '小机器人讲话的时候', title: '重点就在旁边', lines: [{ text: '一块磨砂卡', at: 'c02:旁边' }] }
```

**STICK 贴图**：照片或便签，弹出来，歪一点，顶上一条胶带。

- 照片：`{ t0, t1, src, x, y, w, rot, cap, tag, ring: { u, v, r, at } }`，x、y 是中心
- 便签：`{ t0, t1, note: ['一行', '两行'], x, y, w, h, rot, fs, col }`，字一行行写出来

贴图别压住屏幕上的字。小机器人近景里，贴图放它左边虚掉的地方。

## 游戏画风的屏幕（screen_game.js）和 PAD 手柄

66 期（读博 × GTA6）加的：要「模拟一个场景」又不想用截图、不想用 AI 生成图时，把显示器画成一台像素游戏机。画法挑的是三类：像素复古小屏、程序化生成的地图、游戏 HUD。

**怎么画的**（写新种类也照这几条）：

- 在 `chrome()` 的内容区里开一块 800 宽的小画布（一格 = 屏幕画布 4 像素），画完最近邻放大贴回去。图形按 2 格一个「像素」画，看着像 400 宽的小屏；字按 1 格画，细一点读得清。
- 颜色只用 `PAL` 里那 20 色（暖金色跟书房的金色一致）；字是系统字画一次、按阈值二值化的点阵字，缓存起来。
- 小精灵一格一个字母写在 `SPR` 里：`kaka kaka2 kakasad`（小卡走路两帧、垂头）、`slime boss npc car carside lamp tree rock house crystal heart check cross marker pad coin star flag sword book clock hop golf`。
- 每一帧只依赖 t：随机数都由 `hash` 定，角色位置取整到格子上，所以分块渲染、补渲哪一块都对得上。
- 地图是一格一格「坍缩」出来的（波函数坍缩那种长法），可以再盖一层战争迷雾，小卡走过的地方散开。
- 共用的小动作：`floater` 浮起来的字（「+10 XP」那种），`toast` 弹出来的系统提示框，`walker` / `along` 小卡沿关键帧走（`path: [[时刻, x, y]]`，到下一个点的时刻正好走到）。

**有哪些**（字段写在 `set/screen_game.js` 每个函数开头的注释里，这里只列常用的）：

| kind | 画什么 | 66 期讲到哪句时用 | 常用字段 |
|---|---|---|---|
| `gtitle` | 标题卡：大字 + 小字，背景是星空、地图或正在长出来的地图 | 系列开头、章节里的过门、片尾预告 | `kicker big small at`，`bg: 'stars' 'field' 'grow'`，`spr: [{ name, x, y, sc, at, walk }]`，`hint` |
| `gstat` | 一个大数字，可以从 0 滚上去，下面几行说明 | 「八十个小时」「半夜两点不睡觉非要再跑一个任务」 | `kicker num unit roll numAt`，`lines: [{ text, at, hl }]`，`note icon` |

## PHONE 手机、HOLO 全息、NOTEBOOK 笔记本

三样都放在书桌上，都不凭空出来：手机本来就扣在桌上，全息从小机器人脚下的充电座打出来，笔记本是小机器人飞过去用光线掀开的。不写这几张表，片场照旧，不多建任何东西。

**PHONE** `{ at, t1, back, kind, title, sub, … }`：桌上扣着的手机翻过来亮屏。`at` 开始翻（前面 0.6 秒震两下，像来了消息），翻 0.52 秒，落桌弹一下，屏幕晚半拍亮；`t1` 硬切的那一刻扣回去；要在镜头里翻回去就写 `back: 时刻`。`title` `sub` 屏幕顶上的标题和小字。

- `kind: 'comments'`：评论区，`lines: [{ at }]` 每条评论进来的时刻（只画轮廓，不编具体评论），`hl: { at, text }` 最后一条金边、写着要点
- `kind: 'chat'`：对话，`lines: [{ who: 'me' 或 'ai', text, at, typing }]`，我的在右边；对面先打 `typing` 秒点点点再出字

```js
PHONE: [{ at: 'e03:评论区', t1: 'DUR', kind: 'comments', title: '评论区', lines: [{ at: 'e03:评论区+.6' }, { at: 'e03:评论区+1.0' }], hl: { at: 'e03:弹幕', text: '想看下雨天' } }]
```

**HOLO** `{ t0, t1, kind, kicker, pos, w, … }`：小机器人脚下的充电座朝左前方打出一束光，先拉出一条亮线，再撑开成一块青色的半透明屏，内容扫进来；讲完压回一条线、缩成一个点。屏在 t0 那一刻正对镜头。`pos: [dx, dy, dz]` 相对小机器人站的位置（米，默认 `[-.25, .19, .12]`），`w` 屏宽（默认 .34 米）。

- `kind: 'flow'`：`inputs: [{ text, at, hl, size, code }]` 几项横着排，中间箭头；`hl` 那一刻变暖色；`code: ['一行', …]` 在这一项下面一行行打出来
- `kind: 'merge'`：`inputs` 同上，`join`（默认 `'+'`），`result: { text, at, size }`：几项先排开，到 `result.at` 往中间收，闪一下变成结果
- `kind: 'check'`：`marks: [{ text, at, no }]` 对和错两个大圆，`no: 1` 是打叉

**NOTEBOOK** `{ at, head, inside, lines: [{ text, size, hl, dy }] }` 和 **VISIT** `{ t0, t1, to: [x, z], yaw, pose, fly, aimOff }`：小机器人飞到笔记本后面（VISIT），从手心拉出一根金色光线，先把压在封面上的笔拨开，再勾住封面往上掀，封面落下去弹一下停住；书页上是手写的几行字，说到哪句（`hl`），光线就在哪句底下描一道金线。翻开以后一直开着。

- `at` 光线搭上笔的时刻；封面在 at + 0.7 到 at + 2.5 之间掀开。`head` 书页顶上一行小字，`inside` 封面里侧的一行字，`size` 字号（默认 56），`dy` 和上一行隔多远
- VISIT 的 `t0` 比 `at` 早 1.75 秒左右（飞 1.3 秒，落下再抬手），`t1` 在最后一句描完以后；`to` 落在桌上哪儿（米），`yaw` 落下后朝哪（度），`pose` 没在拉光线时的姿势，`fly` 飞几秒（默认 1.3）。有光线要拉的时候它自己转身、换成 `reach` 往前伸手
- `chk.mjs` 会查每个 NOTEBOOK 旁边有没有 VISIT

```js
NOTEBOOK: [{ at: 'd01+.15', head: '片场笔记', lines: [{ text: '先灰模', size: 90, hl: 'd01:清单' }, { text: '再打光', size: 90, hl: 'd01:打勾' }] }],
VISIT: [{ t0: 'd01-1.6', t1: 'd01$+.6', to: [1.03, .36], yaw: -8, pose: 'present' }],
```

演示表里这三样都没用，写法留在 `shots.js` 文末的注释里。

## 标题、章节、进度条

- **TITLES** `{ t0, t1, kicker, big: [['欢迎来我的', 0], ['片场', 1]], small, dim }`：居中的大标题。big 是几段字，后面写 1 的那段是金色。`dim: 1` 把背后压暗一点
- **CHAPTERS** `{ at, dur, no, num, name }`：章节卡。整个画面虚掉，中间写「第一站 / 01 / 屏幕」，`dur` 秒后画面恢复
- **PROGRESS** `{ t0, t1, items: [{ name, at }] }`：顶上正中的章节进度条，当前那章金色、按进度填满。开头要告诉观众有几章，进度条从第一章开始一直留着

## CTA 引导

`{ at, kind, dur, … }`：

- `like`：三个按钮依次弹出、点亮。`keys: ['like', 'coin', 'fav']`，`text` 按钮上面一行字，`cx, cy` 放哪（不写在右下角）
- `comment`：一个评论框，字一个个打出来。`text`，`typing` 打字用几秒
- `danmaku`：几条弹幕从右往左飘过上半屏。`lines`，`hint` 顶上一行提示

## 其他

- **HERO** `{ t0, t1, dir, fps, n, start, fin, fout, zoom: [z0, z1], label }`：整屏放一段帧序列，盖住三维画面
- **FADES** `{ t0, t1, kind: 'in' 或 'out' }`：黑场淡入淡出

## 给小机器人起名、换颜色

- **起名字**：写进稿子就行。口播里怎么叫它，画面上不用改任何东西。屏幕里的字、贴图、磨砂卡提到它，用同一个名字。
- **换颜色**：导演表写 `KAKA_LOOK: { shell: '#cfe3f1', dark: '#1d2a33', red: '#ffb000' }`，三项可以只写一项。`shell` 外壳，`dark` 脖子、手脚和屏幕边框，`red` 天线头、耳朵和发光的地方（名字是历史原因，填什么颜色都行）。不写就用模板的默认色，在 `kaka_look.js` 的 `KAKA_LOOK0` 里：浅灰白、蓝灰。
- **改形状、脸上的颜色**：改 `set/char/*.ts`，再 `npm run kaka` 重新打包成 `kaka.js`。`rig.ts` 开头写了几种底色在哪。改了底色，`kaka_look.js` 里的 `KAKA_COLORS` 也要跟着改，不然 `KAKA_LOOK` 找不到材质。
- **换完以后重画屏幕里的 2D 小机器人**：`node tools/kaka_png.mjs "$PWD" --pose thumbsUp --face happy`，有 KAKA_LOOK 的话加 `--look '{"shell":"#cfe3f1"}'`。输出透明底的 `media/kaka.png`。
- **换一个完全不同的主持角色**：照 `char/entry.ts` 导出同名的几样（`makeRig applyState STATE0 FACES POSES blinkAt breathAt mixObj`），`makeRig()` 返回的对象里有 `root`、`ground`、`setOutline`，`film.js` 就不用改。脚底中点放在原点，面朝 +z。

## 怎么检查

都在 `set/` 里跑。

**表的体检**，一两秒就完，每次改完都跑：

```bash
node tools/chk.mjs "$PWD"
```

查这些：时间写法能不能换成秒（有解析不了的，退出码是 1）；屏幕中间有没有空档；镜头数、硬切数、太短的镜头；各张表是不是按口播顺序；字块在不在安全区、会不会压在一起；屏幕镜头会不会切掉标题条；小机器人镜头旁边有没有重点；悬浮段够不够 12 秒、有没有叠在一起；猛地换光是不是在硬切上。它只能估，提醒的地方要抽帧看一眼。

**查页面里的一个值**：

```bash
node tools/dbg.mjs "$PWD" "TL.lines.b03.start"
node tools/dbg.mjs "$PWD" "import('./kit.js').then((k) => k.TX('c02:跳进屏幕'))"
node tools/dbg.mjs "$PWD" "film.poseAt(12).p"
```

**抽帧拼图**，一次只渲几帧：

```bash
node render.mjs --page film.html --sheet 2,15.8,31.6,44.9 --cols 4 --w 640 --q ns=4 --out ../out/check/a.jpg
```

一定要带 `--page film.html`。`ns=4` 是每帧采样 4 次，看构图够了；看光和颗粒用 16。网址参数可以写进 `--q`：`clean` 只看三维画面，`cam=talk` 固定在一个机位，`pose=px,py,pz,lx,ly,lz,mm,f` 随手摆一个机位（位置、看向、焦距、光圈），`level=3` 只开到第 3 级，`clay=1` 灰模，`light=night` 换光，`nobed` 这类去掉某样东西。

两版对比：`shots=b` 换用 `shots_b.js` 这张导演表，`tl=draft` 换用 `tl_draft.js` 这条时间线（比如配音还没出来，按字数估的那条）。不写就是 `shots.js` 和 `tl.js`。

抽哪几帧：每个镜头刚开始、字刚落下、动画走完、换屏的前后。便签和清单是一行行写出来的，抽到一半是正常的，往后抽一点再确认。

**光抖不抖**：

```bash
node tools/flicker.mjs "$PWD" 20 8
```

从第 20 秒起连渲 8 帧，量相邻两帧的平均亮度差（满分 255）。同一个镜头里在 0.1 以下算不抖，一般是 0.01 到 0.09。挑镜头停住的地方量。小机器人换姿势、镜头在推的时候，亮度会朝一个方向慢慢变，这不算抖；抖是一高一低来回跳。

**几个机位、几级开关拼一行**：

```bash
sh sheet.sh views ../out/check/views.jpg 20 "clean" wide talk board top
sh sheet.sh levels ../out/check/lv.jpg 20 "cam=wide&clean" 0 1 2 3 4 5 6 7
```

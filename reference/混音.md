# 混音

声音分三条：人声、配乐、音效和环境声。电平、均衡、压缩、侧链都在 `juzu stems` 里用 ffmpeg 做完，出成三条分轨交给达芬奇。达芬奇里三条原样相加就是成片的声音，推子不用动。

下面的数都来自 64 期。那一期作者听过成片，认可这套电平。用 64 期的素材重跑 `stems.py`，结果和当时一样：三条相加 −16.2 LUFS，真峰值 −1.2 dB，和当时的混音参考逐段相减，差在 −45 dB 以下。

## 人声

| 处理 | 数 | 为什么 |
|---|---|---|
| 有声部分拉到 | −20 dB RMS | 只算振幅超过 0.01 的样本，句间停顿不拉低平均，每期的人声音量一致 |
| 高通 | 70 Hz | 去掉喷麦和桌面的低频 |
| 3 kHz 提亮 | +2 dB | 手机外放时字更清楚 |
| 压缩 | 2.5:1，阈值 −18 dB，起音 8 ms，释放 150 ms | 轻压，只把忽大忽小收一点 |

## 配乐

| 处理 | 数 | 为什么 |
|---|---|---|
| 每段铺底母带 | −20 LUFS（`juzu master_beds`） | 各段一样响，换段时不跳 |
| 去哨音 | `despur.py`：2.5 到 18 kHz 里长时间不动、比周围高 6 dB 以上的窄线压下去 | ACE-Step 解码器留下的细线听着刺耳（65 期） |
| 母带均衡 | 30 Hz 低切，300 Hz −2 dB，2.5 kHz −3 dB，4.8 kHz −1.5 dB，8 kHz 高架 −2 dB，15 kHz 缓低通，2:1 压缩 | 去闷、给人声让位；高频收一点，65 期原来 9 kHz 提 1.5 dB 被说刺耳 |
| 分轨里整体 | −13 dB（`levels.bed_db`） | 64 期试出来的；taowa 默认 −7，用在平缓的钢琴弦乐上偏响 |
| 再让出 2.5 kHz | −3.5 dB | 人声最清楚的频段留给人声 |
| 侧链 | 5:1，阈值 0.02，起音 20 ms，释放 900 ms | 人声一出来配乐就往下让，停顿时慢慢回来；400 ms 时句子间隙配乐会往上冒 |
| 开场那段的增益 | plan 里 +4 | 之前给到 +11，开场太响，总峰值超了 |

开场那段不过铺底的母带，原样转成 48 kHz：开场要保住从安静到展开的起伏。

## 音效和环境声

- 柔和音效（章节气声、小铃、轻敲）：每个文件校到最大瞬时响度 −30 LUFS，原样摆，比人声低约 10 LU。
- 片场动作声：基准 −34 LUFS，比柔和音效再低 4 dB。64 期有 59 处，比章节气声多得多，所以更轻。
- 环境声：整段先统一到 −24 LUFS，分轨里再调到比同一时段的配乐低 `under_music` 个 LU（默认 7）。64 期开场：配乐 −16.2 LUFS，音效轨 −23.3 LUFS。65 期整条片子底下的窗外声用 12。

## 总响度和限幅

- 三条乘同一个增益，加起来正好 −16 LUFS。这是前几期一直用的目标，64 期成片也按它交。
- 真峰值不超过 −1 dB，压成 AAC 以后才不会削顶。
- 限幅放在增益**之后**。之前放在前面，增益一加，总峰值冒过 0 dB。
- 限幅线：人声从 −2 dB 起，总峰值超了就一次压 1 dB，最多到 −5；配乐 −4；音效 −9（柔和音效本来就不该有尖峰）。64 期压到人声 −3 dB 就够了。
- 压到 −5 还超，多半是配乐某一段太响。回去改 `cues.json` 的 plan gain 或者 `levels.bed_db`，别继续压人声。

## 混音参考

`stems.py` 同时出 `out/mix_ref.wav`：三条直接相加的结果。达芬奇出片以后，拿成片的声音和它做互相关（`juzu verify`），偏移应该是 0 毫秒。64 期在片子的 1/4、1/2、3/4 三处量，都是 0。

## 踩过的坑

| 现象 | 原因 | 办法 |
|---|---|---|
| 成片里没有章节气声、小铃、片尾的低音 | 64 期先摆好音效写进 `out/sfx.wav`，后来又跑了一次配乐拼接，把同名文件覆盖成了空的 | 柔和音效现在写 `out/sfx_cues.wav`，拼接只写 `out/bed.wav`，两边不再共用文件 |
| 分轨比画面长约 1 秒 | ffmpeg 的 `-t` 只管紧跟着的第一个输出，配乐和音效没被截 | 三条都按时间线时长截；达芬奇里再用 MarkIn / MarkOut 卡住画面的帧数 |
| 总峰值超 0 dB | 开场配乐太响，人声限幅放在了加增益之前 | 开场增益 11 改 4，限幅挪到增益之后 |
| 环境声开头空了 1 秒 | 第一段也做了 0.2 秒的预卷，被提前到了片子开头之前 | 第一段 `pre` 是 0 |
| 音效库截到安静处，校准以后全是底噪 | 随便截了一段 | `set_fx.py` 的 `lib()` 挑录音里最响的几段 |
